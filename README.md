# Trouvus website redesign prototype

## Included pages
- `index.html` — homepage
- `expertise.html` — five practice areas
- `approach.html` — Strategy-to-Scale Framework
- `results.html` — evidence architecture
- `insights.html` — cornerstone editorial program
- `about.html` — company and founder positioning
- `contact.html` — consultation conversion page
- `styles.css` and `script.js` — responsive design system

## Preview
Open `index.html` in a browser. All pages are static and can be hosted on Netlify, Vercel, GitHub Pages or conventional hosting.

## Before production launch
1. Replace prototype evidence cards with verified, permissioned engagements.
2. Connect the contact form to Wix Forms, HubSpot, Formspree, a CRM or a server endpoint.
3. Add final privacy, terms, accessibility and responsible-AI pages.
4. Add approved founder photography and real workshop/client imagery.
5. Confirm all claims, credentials, phone numbers and service-delivery wording.
6. Add analytics, consent management, canonical URLs, social metadata and structured data.
7. Configure redirects from the current Wix URLs.

## Migration options
- **Wix Studio:** recreate components and paste approved copy; best if retaining the existing platform.
- **Webflow:** strong editorial control and CMS structure.
- **WordPress:** suitable when publishing volume and extensibility are priorities.
- **Custom/Next.js:** best for maximum performance and product-like interactive tools.

## Evidence policy
Every published proof item should be labelled as one of:
- Verified client engagement
- Anonymized client engagement
- Research/intellectual evidence
- Illustrative scenario

Never publish a hypothetical scenario in a visual form that implies completed client work.
